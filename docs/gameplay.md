# 玩法说明

## 创建角色

输入 1–12 个字符的名字，选择职业、体型、六种发色之一和三种发型之一。拖动预览或点击箭头可以旋转角色。基础职业与进阶职业都可以直接创建，每个角色有自己的独立存档。

| 职业系 | 基础职业 | 进阶职业 |
| --- | --- | --- |
| 初心 | 初心者 | — |
| 剑士 | 剑士 | 骑士、十字军 |
| 魔法 | 魔法师 | 巫师、贤者 |
| 弓箭 | 弓箭手 | 猎人、吟游诗人、舞娘 |
| 圣职 | 服事 | 牧师、武僧 |
| 商人 | 商人 | 铁匠、炼金术士 |
| 盗贼 | 盗贼 | 刺客、流氓 |

各职业的属性、武器、外观与四个技能均有区别；数值和技能组合针对单人网页冒险进行了重新设计。

## 三章旅途

| 地图 | 目标 | 领取奖励 |
| --- | --- | --- |
| 晨曦山谷 | 击败 5 只波利 | 到入口附近与莉露交谈 |
| 萤语森林 | 击败 5 只波利 | 与菲恩交谈 |
| 星落遗迹 | 击败波利女王 | 返回入口与星语者交谈 |

沿路往北走，穿过光门可以前往下一张地图；南面的光门可以返回。任务按章节顺序领取奖励。完成遗迹任务后获得永久波利伙伴，并可继续探索。

## 战斗与女王

点击魔物会选择目标、自动靠近并持续普通攻击。`Space` 攻击当前目标，或选择附近的魔物；`Tab` 切换目标，`1`–`4` 使用技能。移动操作会取消自动攻击，便于躲避范围技能。

波利女王有 720 点生命。她的「糖霜冲击」会先在地面显示预警法阵，走出光圈可以躲避伤害。竞技场中央缓慢旋转的金色纹样是场景装饰。

女王被引出领地后会实际返回出生点，目标栏会显示「返回领地」。返回途中仍可受到普通攻击、技能和持续伤害；持续战斗不会反复触发回血。只有回到出生点、玩家已经远离且没有持续中毒时，才会恢复一次部分生命。

## 成长与补给

- 战斗奖励自动进入背包，升级会恢复生命与 SP。
- `Q` 使用红色药水恢复 50% 生命，`E` 使用蓝色药水恢复 60% SP。
- 靠近向导按 `F` 可以领取任务奖励、购买药水和出售凝胶。
- 地图上的宝箱会提供金币、药水和永久提升最大生命的卡片。
- 背包中可以消耗金币与凝胶强化武器，最高强化到 +10。
- 倒地后可以回到当前地图入口，等级、背包与任务进度保留。

## 存档与设置

进度保存在当前浏览器的 `localStorage`，存档键为 `dreamro.adventurers.v1`。游戏会定时保存，并在拾取、升级、换图和离开页面时保存；设置中也可以手动保存。

每个访问地址有独立存档。`localhost:5174` 和 `dreamro.hexly.ai` 不共享进度，更换浏览器或清理站点数据也不会自动恢复。当前版本提供本地角色列表，没有云端账号或多人联机。

设置中可以切换音乐、音效、音量与画质。设备发热或帧率偏低时，选择「流畅」。镜头被树冠遮挡时，遮挡角色或当前目标的树叶会自动淡出。
